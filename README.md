# 📘 AEDS — Algoritmos e Estruturas de Dados

Repositório destinado ao estudo e implementação de **Algoritmos e Estruturas de Dados (AEDS)**.
Contém exercícios, exemplos, materiais de apoio e códigos desenvolvidos em **C**, **C++** e **Java**.
